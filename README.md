# Healthcare Analytics for Doctor Visits

This project explores the supplied doctor-visits dataset using descriptive statistics, group comparisons, correlation analysis, visualizations, and an exploratory Random Forest regression baseline.

## Files
- `Healthcare_Analytics_Doctor_Visits.ipynb` — analysis notebook
- `Healthcare_Analytics_ProjectReport.docx` — project report
- `Healthcare_Analytics_Doctor_Visits_Presentation.pptx` — presentation based on the supplied template
- `requirements.txt` — Python dependencies
- `data/healthcare_doctor_visits.csv` — dataset
- `outputs/` — generated chart outputs (see report/notebook for visualizations)

## Run
Install Python 3, then run `pip install -r requirements.txt`, then `jupyter notebook` and open the notebook. Run cells from top to bottom.

## Interpretation
This is an educational analysis. Correlation is not causation, and results must not be used for medical diagnosis or clinical decisions.
